Quick answers

Where do I get an API key?

Tap the key icon in the top bar. Open “How to get an API key” for the steps and a direct ElevenLabs link.

Why does Auto tag skip some lines?

A tag keeps working until the emotion changes, so the same tag is not repeated on every line. Change the strength in Profile → Auto tag.

Are tags supported on every model?

Expressive tags work best with Eleven v3. Other models may read them out or ignore them.
