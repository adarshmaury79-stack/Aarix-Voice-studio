Quick answers

Where do I get an API key?

ElevenLabs dashboard → Developers → API Keys. Create one and paste it in Profile → API key.

Why do I hear a different voice?

Tap a voice row once and it is selected immediately. The audio card shows the exact voice used for each generation.

Are tags supported on every model?

Expressive tags work best with Eleven v3. Other models may read them out or ignore them.
